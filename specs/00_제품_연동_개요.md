# 디지털 자산 거래 플랫폼 · AI 에이전트 연동 개요

**목표:** 소규모 디지털 프로젝트를 탐색·평가·협상·인수할 때, 대화형 에이전트가 거래 플랫폼 API를 이용해 사용자의 업무를 지원한다.

## 서비스 구성

| 구성 | 책임 | 현재 기술 구조 |
|---|---|---|
| 거래 플랫폼 | 매물, 사용자, 권한, 제안 및 거래 상태의 원본 | Replit에서 독립 운영되는 웹/API 서버(연동 준비 중) |
| AI 에이전트 | 자연어 해석, 도구 선택, 추천·정적 실사·협상 초안·작업 기록 | Python 3.12, Streamlit 1.67, LangChain, SQLite |
| 외부 모델 | 사용자의 대화를 도구 요청으로 변환하고 결과를 설명 | OpenAI API, 키가 없으면 제한된 규칙형 실행 |

## 운영 원칙

1. VS Code에서는 `python -m streamlit run app.py` 한 명령어로 에이전트를 실행한다. 별도 로컬 FastAPI 서버나 Mock Marketplace 서버는 실행하지 않는다.
2. 에이전트는 독립 플랫폼에 HTTP API로 접근하며, 플랫폼 DB에 직접 접근하지 않는다.
3. `AGENT_MODE=mock`에서는 샌드박스 데이터와 SQLite만 사용한다. `AGENT_MODE=live`에서는 API 읽기만 지원하고 거래 변경은 차단한다.
4. 실제 플랫폼은 원본 계정/거래 기록의 유일한 기준이며, `MARKETPLACE_API_KEY`와 Bearer JWT의 최종 인증 계약은 추후 확정한다.
5. 모델이 제안한 도구 호출은 허용 목록과 정책 검사에 의해 제한된다. 외부 제안·수락·인수 상태 변경은 사용자가 승인 버튼으로 확인해야 한다.
6. 정적 실사에서는 미확인 내용을 `UNKNOWN` 또는 `NOT_TESTED`로 기록하며, 법적 권리·가동 안정성·수익을 보증하지 않는다.
7. 유료 API, 비신뢰 코드 실행, 외부 거래 변경은 별도 권한 검증 없이 자동화하지 않는다.

## 핵심 업무

- **구매:** 매물 검색 → 맞춤 추천 → 메타데이터 검사 → 조건부 구매 제안 초안 → 사용자 승인.
- **판매:** 매물 검사 → ZIP 정적 분석 → 보완사항 보고 → 역제안 초안 → 사용자 승인.
- **인수:** 샌드박스 거래 상태 검토 → 체크리스트 확인 → 증빙과 누락 사항 기록.
- **품질:** 정적 검사 증빙, 도구 실행 이력, 중복 요청 방지, API 계약 및 회귀 테스트.
