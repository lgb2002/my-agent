# ProjectAgain Agent v0.16

**채팅 중심 디지털 프로젝트 거래 AI 에이전트 — 단일 Streamlit 앱.**

Python 3.12, Streamlit, LangChain, OpenAI, ProjectAgain Replit API를 사용합니다. 별도 에이전트/FastAPI 서버가 필요하지 않습니다. 기존 13개 도구, 사용자별 12시간 위임 토큰, Live의 기본 읽기 전용 정책과 DEMO 사용자 승인 버튼을 유지합니다. 실플랫폼 초안 제출은 별도 옵션을 켠 경우에만 사람의 확인 버튼으로 시작합니다.

## v0.16 — AI 적합성 평가 가시화 및 공개 AI 사용량 보호

기존 v0.13~v0.15에 구현된 공개 매물 근거 기반 AI 정성 평가를 유지하며, 이번 버전에서는 추천 후보마다 **규칙 기반 기본점수 · AI 선호 보정 · 인용 근거**를 분리해 표시합니다. 사용자 선호에 맞는 이유를 설명하는 도구이지, 수익·권리·보안을 보증하는 가치평가 시스템은 아닙니다.

**공개 운영의 중요한 변경:** OpenAI 키만 설정된 상태의 무인증 채팅에서는 유료 AI를 호출하지 않습니다. 자기 ProjectAgain 위임 토큰 검증 또는 Streamlit OIDC 로그인이 필요하며, 공용 PostgreSQL에서 사용자/전체 호출·예상 비용 한도를 검사합니다. 인증이나 PostgreSQL이 없더라도 일반 공개 매물 조회는 계속 가능합니다.

- 필수 운영 패키지: `psycopg[binary]` (`AGENT_STATE_DATABASE_URL` 또는 `AI_USAGE_DATABASE_URL`을 설정한 경우)
- 선택적 OIDC 로그인: `streamlit[auth]` + Streamlit Secrets `[auth]` 설정
- 실행: `python -m streamlit run app.py` (FastAPI 별도 실행 불필요)
- 기존 `.env`, `.venv`, `requirements.txt`, `data/`를 덮어쓰지 마세요.

**Secrets 설정, 사용자 인증, 호출 한도·모델 단가 관리, 한계 및 테스트**: [`docs/AI_FIT_AND_PUBLIC_QUOTAS_V016.md`](docs/AI_FIT_AND_PUBLIC_QUOTAS_V016.md) / [`README_V016.md`](README_V016.md).

이 버전은 v0.14의 다단계 실행 및 13개 도구를 보존하며, 사용자의 현재 목표를 마무리하는 데 필요한 정보와 상태를 더 명료하게 만듭니다.

| 영역 | 실제로 추가·변경한 부분 | 적용 범위 |
|---|---|---|

| 플랫폼 승인 연동 | `ENABLE_LIVE_DRAFTS` 선택 활성화 시 **실명 위임 토큰 소유자가 직접 확인한** `SUBMIT_OFFER` 초안만 등록, 플랫폼 액션 상태 GET 조회 | **기본 비활성**, 플랫폼 웹에서만 승인/실행. 돈·계약·권리 이전 연동 안 함 |

| 운영 데이터 | 이미 있던 SQLite/PostgreSQL 선택 저장에 연결 상태 검사를 추가, 불안정 저장과 영속 저장 구분 | 실제 PostgreSQL 연결은 배포 환경에서 테스트 필요 |

**중요: Live 플랫폼 초안 API는 아직 실환경 계약 미검증 상태입니다.** v0.13 플랫폼 소스의 최신 요청 스키마와 `Idempotency-Key` 처리 보장을 검증하기 전까지 `ENABLE_LIVE_DRAFTS=false`를 유지하세요. 설정을 켜더라도 Streamlit은 **초안 등록 및 원격 상태 조회만** 할 수 있고 `approve`, `reject`, `execute`를 호출하지 않습니다. 사용자 동의로 저장한 작업 계획에는 초안 ID만 보존하며, 승인 권한이나 승인 버튼은 복원하지 않습니다. 플랫폼 사용자의 `offer:draft` 범위가 확인되어야 하며, 계정이 바뀌면 이전 초안을 제출할 수 없습니다. 네트워크 타임아웃 시 자동 재전송하지 않고 상태 확인을 요구합니다.

### Cloud 영속 저장 설정

외부 DB의 비밀 URL을 `AGENT_STATE_DATABASE_URL`에 넣고 `psycopg[binary]`를 설치하면 계정별 승인된 작업 계획과 선호 저장을 시도합니다. 데이터베이스 연결 건강 상태를 UI에 표시하지만, 본 대화에서 사용자 DB와의 실제 연결 또는 재배포 후 복구는 검증하지 않았습니다. 로컬 SQLite는 Cloud 재배포 이후 보존되지 않을 수 있습니다.

### 기존 API/비밀 설정 유지

- `AGENT_MODE=mock` 또는 `live`, `MARKETPLACE_API_URL=https://호스트` (중복 `/api/v1` 없이)
- `MARKETPLACE_INCLUDE_DEMO=true`, `ENABLE_OPENAI_CHAT=true`와 개인 OpenAI 키
- 플랫폼 위임 토큰은 공용 Secrets에 넣지 않고 **각 사용자의 사이드바 암호형 입력**으로 관리
- `ENABLE_LIVE_DRAFTS=false` (기본값, 실제 인증/스키마/멱등성 테스트 완료 전 유지)

자세한 보안 경계, 테스트, 실제 연동 전 체크리스트: `docs/INTEGRATION_AND_UX_V015.md`.

## v0.14 — 다단계 업무 계획·선호 기억·결과 검증

이번 버전은 기존 13개 도구를 유지하며, 추천 중심의 **복합 목표**를 한 작업으로 이어서 진행합니다. 일반 단일 도구 요청은 이전과 같은 경로를 사용합니다.

1. **목표 분석:** OpenAI 구조화 출력으로 “프로젝트 선별 → 후보 비교 → 공개 정보 점검 → 구매 제안 준비” 요청을 확인하고 최대 5개 단계(최종 검증 포함)로 계획합니다. 임의의 외부 도구·HTTP URL을 실행하지 않습니다.
2. **정보 확인:** 추천에 필요한 구매 목적·예산·개발 수준·위험 조건을 기존 v0.13 의미 검증을 거쳐 수집합니다. 부족한 조건을 묻고 그 시점에 **WAITING_INPUT**으로 기록합니다.
3. **단계적 실행:** 실제 추천 도구가 반환한 후보 UUID를 비교와 정적 점검에 이어 사용합니다. 검색 결과가 부족하면 없는 매물을 채우지 않고 미달 사유를 남깁니다.
4. **제안 금액 별도 확인:** 구매 예산을 제안 가격으로 자동 사용하지 않습니다. Mock에서만 기존 사용자 승인 카드를 열며, 제안의 **생성·승인·전송은 사용자 버튼 없이 수행하지 않습니다.** Live에서는 조회/정적 분석만 진행합니다.
5. **검증 및 중단:** 단계별 `COMPLETED`, `PARTIAL`, `FAILED`, `WAITING_*`, `BLOCKED` 상태를 사용합니다. 사용자 목표 달성 여부, 근거가 부족한 부분, 소스 실행·매출·권리 검증의 한계를 구분합니다. 실패한 단계는 사용자 **이어하기** 조작 후 재시도할 수 있으며 완료된 단계는 자동 중복 실행하지 않습니다.

**예시:** “50만원 이하 수익화 프로젝트 중 후보 3개 비교하고 가장 적합한 매물 위험 분석 후 구매 제안 준비해줘.” → 구매 조건 확인 → 추천 → 최대 3건 비교 → 1위 공개 메타데이터 점검 → Mock이면 제안 금액 질문 → 승인 카드. Live에서는 제안 변경을 시도하지 않습니다.

### 확인된 사용자 선호와 작업 기억

기본은 **현재 브라우저 대화 세션에서만 유지**됩니다. 개인별 장기 저장은 기본 비활성화입니다. Live 모드에서 사용자가 직접 입력한 **자기 위임 토큰으로 `/auth/me` 인증이 성공하고**, 사이드바의 “내 작업 · 기억”에서 저장에 동의한 경우에만 다음 정보를 기록합니다.

- 사용자가 확인한 구매 목적·예산·기술 수준·위험 허용 등 필수 선호 항목
- 작업 계획의 단계별 상태와 공개 매물 UUID/비교 요약/미검증 사유

**저장하지 않음:** OpenAI 키, 위임 토큰, 전체 채팅 기록, 원본 비공개 파일, 승인 페이로드, 원본 API 응답. 저장된 조건/계획은 계정별로 격리하며 사용자가 불러오거나 삭제할 수 있습니다. 저장은 사용자 인증을 대신하지 않습니다.

기본 SQLite 파일은 로컬 프로세스 재시작 시 남을 수 있지만 **Streamlit Community Cloud 재배포·재시작·컨테이너 교체에 대한 영속성은 보장되지 않습니다.** Cloud에서 계획을 장기간 복원하려면 외부 PostgreSQL 저장소와 비밀 설정을 사용하세요.

PostgreSQL을 선택할 때만 추가 설치:

```bash
python -m pip install "psycopg[binary]"
```

Streamlit Cloud Secrets 또는 `.env`에 `AGENT_STATE_DATABASE_URL`을 설정합니다. URL에 DB 비밀번호가 포함되므로 절대 GitHub에 업로드하지 마세요. PostgreSQL 연결은 환경이 준비되어야 검증 가능하며, 이번 자동 테스트는 SQLite를 대상으로 수행했습니다.

### 버전 호환성과 범위

기존 `app.py` 하나로 실행하며 FastAPI 서버 추가는 필요 없습니다. 일반 13개 도구의 LLM 호출 경로, 공개 API 조회, 추천 근거 검증, 사람 승인 정책은 유지했습니다. 복합 계획 엔진의 첫 지원 범위는 **추천 → 비교 → 공개 정보 점검 → DEMO 제안 준비 → 결과 검증**입니다. 다른 종류의 모든 도구를 자유롭게 계획·조합하는 범용 실행 엔진까지 완성한 것은 아닙니다.

새 플로우의 모델 분류·제안 금액 추출 등으로 기존보다 OpenAI 호출이 증가할 수 있습니다. **공개 앱에서의 사용자별 호출량·비용 제한은 아직 별도 운영 과제**입니다.

자세한 구조·검증: `docs/WORKFLOW_V014.md`.

## v0.13: 조건 해석 검증 · 정성 선호 반영 · 저위험 근거 평가

v0.12의 OpenAI 중심 대화 및 기존 13개 도구를 유지하면서 **추천 기능 세 가지(A/B/C)**를 개선했습니다.

- **A / 의미 검증:** 모델의 카테고리 추출을 무조건 신뢰하지 않습니다. 사용자 인용과 반대되는 기술 수준·위험 허용도·목적을 차단하고, 모호하면 다시 질문합니다. 월 운영비와 구매 예산의 증거 인용을 분리합니다.
- **B / AI 정성 평가:** 사용자가 말한 운영 편의·자동화 선호 등은 추천 작업에 전달됩니다. 1차 하드 필터를 통과한 후보만 공개 자료를 토대로 OpenAI가 추가 비교하며, 인용이 확인된 경우에만 제한적으로 순위를 조정합니다. 정보가 부족하거나 모델 평가에 실패하면 정성 점수를 주지 않습니다.
- **C / 위험 기준:** `LOW`에서는 검사 미확인, 초급 역량 대비 높은 기술 복잡도, 월 운영비 상한 아래 비용 미확인, 권리 범위 미확인, 심각한 알려진 결함 등을 엄격하게 처리합니다. 결과 0건은 추천할 만큼 검증된 근거가 없다는 뜻일 수 있습니다. 위험 항목의 미확인을 '안전'으로 표현하지 않습니다.

추천 점수는 검증된 투자 수익률이 아니라 가중치 기반 비교 도구입니다. **기본 점수와 AI 보정 점수는 구분**해 표시합니다. AI가 취향을 평가해도 예산·권한·위험 하드 필터를 우회할 수 없습니다.

상세 설명: `docs/RECOMMENDATION_EVIDENCE_V013.md`.

## v0.12부터 유지되는 OpenAI 대화 엔진

OpenAI가 활성화된 상태(`ENABLE_OPENAI_CHAT=true`, `OPENAI_API_KEY` 설정)에서의 모든 사용자 메시지는 다음과 같이 처리됩니다.

1. **의도 분기 및 추천 조건 구조화:** `ChatOpenAI.with_structured_output(RecommendationTurn, method="json_schema", strict=True)`로 추천 요청/후속 답변/그 밖의 요청을 구분합니다. 구매 목적, 예산, 월 운영비, 개발 수준, 위험 허용도, 기술, 유형, 기타 선호를 **한 메시지에서 동시에 추출**합니다.
2. **사용자가 말한 근거 확인:** 모델이 추출한 신규 조건에는 **이번 사용자 메시지의 실제 인용 구절**이 필요합니다. 숫자·원화 단위는 Python 코드로 다시 검증하고, 허용 필드만 세션에 저장합니다. 확인되지 않은 값은 사용하지 않습니다.
3. **필요한 것만 질문:** 구매 목적·예산·개발 수준·위험 허용도가 아직 비었다면, 이미 받은 조건을 표시하고 빠진 한 가지 조건에 관해 질문합니다. 사용자가 분명히 생략을 승인한 항목에만 한정된 기본 가정을 적용하며 결과에 밝힙니다.
4. **추천 도구 실행:** 조건이 채워지면 기존 `ToolDispatcher`의 `recommend_listings` 도구를 **한 번** 호출합니다. 추천 후보의 예산/기술/유형 필터, 규칙 기반 점수, 원본 근거는 Python이 담당합니다. 모델이 임의로 추천 도구 호출의 필수 조건 검사를 건너뛸 수 없습니다.
5. **AI 설명은 별도 표시:** 추천 결과가 있으면 모델이 기존 도구 결과를 바탕으로 정성적 해설을 덧붙일 수 있습니다. 실제 매출·기술 검증·권리 이전에 대해 근거 없는 주장을 해서는 안 됩니다. 해설이 실패해도 원본 도구 결과는 표시됩니다.
6. **일반 요청은 전체 13개 도구:** 추천이 아닌 검색/실사/제안 초안/인수인계 등은 기존 `bind_tools()`로 모델이 도구를 선택합니다. 거래 변경은 기존 정책과 사용자 승인 없이는 실행할 수 없습니다.

### 자연어 테스트 시나리오

- `나에게 맞는 프로젝트 추천해줘` → 모르는 목적을 묻기
- `수익용이고 예산 50만원, 개발은 파이썬 중급이고 위험은 낮은 게 좋아` → 조건 네 가지를 동시에 확인해 추천
- `수익 창출이 목적이고 예산은 80만원, 월 운영비는 5만원, Python 중급, 저위험` → 금액 두 개를 서로 혼동하지 않기
- `아까 예산 80만원이라고 했는데 50만원으로 바꿔줘` → 기존 문맥의 예산 수정
- `개발 수준은 잘 모르겠어` → 해당 질문에만 승인된 기본 가정 적용 및 표시
- `매물 목록 먼저 보여줘` → 진행 중인 추천을 지우지 않고 일반 도구 호출
- `내 프로필로 추천해줘` → 본인 위임 토큰에 `buyer_profile:read` 권한이 있을 때만 저장 조건 조회
- `취소` → 진행 중인 추천 조건 확인 중지

**주의:** 모델이 이해한 값이 구조적으로 유효하다고 해도 항상 의미적으로 정확하지 않을 수 있습니다. 추천 시작 전에 화면에 표시된 조건을 읽고 수정할 수 있습니다. `운영이 쉬운 것` 등의 추가 선호는 실제 공개 자료에 인용 근거가 있을 때만 AI 정성 보정에 제한적으로 사용하며, 자료가 부족하면 미확인 상태로 유지합니다. 사용자 입력에 명확한 근거가 없거나 금액 단위가 모호하면 질문합니다.

## 설치와 실행

기존 v0.13의 `my-agent` 폴더를 먼저 백업하세요. 이 ZIP의 소스 파일을 **병합**하되 기존 `.env`, `.venv`, `requirements.txt`, `data/`를 삭제·덮어쓰지 않습니다. `app.py`와 `agent/`, `core/`, `services/`, `assets/`, `fixtures/`가 함께 있어야 합니다.

기존 Python 3.12 환경에 `streamlit`, `python-dotenv`, `langchain`, `langchain-openai`, `requests`가 설치되어 있다면 **기본 실행을 위한 추가 설치 패키지는 없습니다.** 확인 명령:

```bash
python -m pip check
python -m pip show streamlit langchain langchain-openai python-dotenv requests
```

미설치 시:

```bash
python -m pip install streamlit python-dotenv langchain langchain-openai requests
```

이전과 동일하게 한 명령어로 실행합니다.

```bash
python -m streamlit run app.py
```

### 설정

로컬 `.env` 또는 **Streamlit Cloud Secrets**에서:

```toml
AGENT_MODE = "live"
MARKETPLACE_API_URL = "https://실제-Replit-플랫폼-호스트"
MARKETPLACE_AUTH_SCHEME = "bearer"
MARKETPLACE_INCLUDE_DEMO = "true"
OPENAI_API_KEY = "실제-OpenAI-키"
OPENAI_MODEL = "gpt-4.1-mini"
ENABLE_OPENAI_CHAT = "true"
SHOW_DEVELOPER_TOOLS = "false"
```

Secrets는 TOML이므로 실제 키는 따옴표로 감쌉니다. `.env`는 TOML이 아닌 `KEY=value` 형식입니다. **GitHub에 `.env`를 업로드하지 마세요.** ProjectAgain 위임 토큰은 앱 공용 Secrets에서 읽지 않고 사용자가 본인의 토큰을 사이드바에 입력하는 구조를 유지합니다.

`ENABLE_OPENAI_CHAT=false`이거나 API 키가 없으면 **제한된 로컬 규칙 모드**로 동작합니다. 이 모드의 추천은 자연어 LLM 분석 결과가 아닙니다. 반대로 OpenAI 모드의 분석 요청이 실패하면 임의의 규칙 기반 결과로 대체하거나 추천 도구를 실행하지 않습니다.

### 비용·공개 배포 주의

OpenAI 모드는 일반 요청에서도 **조건 분석/의도 분기 1회 + 필요한 경우 도구 선택/요약 추가 호출**이 발생합니다. 추천 결과 해설에도 별도 호출이 있을 수 있어 기존보다 사용량이 증가합니다. 공개 앱에서 방문자별 로그인·사용량 통제가 없는 상태로 유료 API를 켜면 과금 위험이 있습니다. 서비스 공개 수준에 맞게 별도 접근 제한·요청 한도를 갖춰야 합니다.

실거래 계약/결제/실제 매물 변경은 허용하지 않습니다. Live의 **기본 정책은 GET 조회 전용**입니다. 예외적으로 `ENABLE_LIVE_DRAFTS=true`와 본인 권한 및 사용자 확인이 모두 충족된 경우에만 구매 제안 **초안**을 제출할 수 있습니다. 승인·실행은 이 앱에서 하지 않습니다. Mock은 모두 가상의 샌드박스 데이터입니다.
