# ProjectAgain Agent v0.14 — 다단계 실행·기억·검증

## 목표 및 실제 지원 범위

- 사용자의 복합 자연어 요청(추천→비교→공개 정보 점검→구매 제안 준비)을 OpenAI Structured Outputs로 분류합니다.
- 5개 이내의 허용된 단계에서 기존 ToolDispatcher 도구를 순서대로 호출합니다. 추천은 기존 v0.13 구조화 조건 확인과 의미 검증을 통과해야만 도구에 도달합니다.
- 후보 목록은 실제 API 결과의 UUID로 고정합니다. 비교는 결과에 존재하는 자료만 사용하며, 소스 실행·매출·권리의 검증을 만들어내지 않습니다.
- 구매 예산과 **구매 제안 가격은 다른 입력**입니다. 일반 구매 예산 표현에서 제안 금액을 추측하지 않습니다.
- LIVE는 GET+로컬 메타데이터 정적 분석만 가능합니다. DEMO의 제안은 기존 사용자 확인 카드가 생성될 뿐이며 승인과 전송은 오직 사람의 버튼에 의해 발생합니다.
- 일반 13개 도구의 기존 단일 요청 / LLM 도구 호출 동작은 유지합니다.

## 실행 흐름

```text
사용자 목표
  └─ OpenAI 추천 의도 확인 및 복합 목표 분류
      └─ 구매 목적·예산·개발 수준·위험 허용 확인 (미확인 시 WAITING_INPUT)
          └─ recommend_listings: 후보 UUID·순위 저장
              └─ compare: 실제 후보 1~3건 비교 (부족하면 PARTIAL)
                  └─ inspect: 상위 후보 공개 메타데이터 점검, 실구동 미검증
                      └─ prepare_offer: LIVE BLOCKED / DEMO에서 가격 확인 후 승인 카드
                          └─ verify: 단계 완료 여부, 부족한 근거, 남은 사용자 승인 명시
```

계획 상태: `ACTIVE`, `WAITING_INPUT`, `WAITING_OFFER_PRICE`, `INTERRUPTED`, `FAILED`, `PARTIAL`, `COMPLETED`, `CANCELLED`.
각 단계는 `PENDING`, `RUNNING`, `WAITING_INPUT`, `WAITING_APPROVAL`, `COMPLETED`, `PARTIAL`, `SKIPPED`, `BLOCKED`, `FAILED`, `INTERRUPTED`.

실제 검증 대상이 아닌 것을 확정적으로 성공이라고 쓰지 않습니다. 수익성 관련 판매자 고지와 검증 자료는 구분하며, 별도의 실행·권리 확인이 없으면 일부 요구만 처리한 것으로 표시합니다. 사용자의 목표를 완전히 충족하지 못해도 도구 실행 성공은 도구 기록으로 남습니다.

## 저장·보안 정책

**기본값은 세션 전용**: 별도 저장하지 않습니다. 계정별 장기 저장은 LIVE 모드에서 사용자가 위임 토큰을 입력해 실제 `/api/v1/auth/me` 검증에 성공하고 저장에 명시적으로 동의한 경우에만 활성화됩니다. 소유권 경계는 `SHA256(플랫폼 원점 + 사용자 ID)`로 생성하며, 실제 토큰은 영구 저장하지 않습니다. 다른 사용자로 조회하거나 삭제할 수 없습니다.

저장 범위: 제한된 계획 상태, 공개 매물의 ID·제목·점수·일부 근거, 확인된 구매 조건. **저장 금지**: 위임 토큰, OpenAI 키, 원본 대화, 원본 비공개 자료, 승인 페이로드, 비공개 도구 JSON.

- 로컬 SQLite: 단일 PC 로컬 프로세스 재시작 시 파일이 남습니다. **Streamlit Cloud의 재시작/재배포 중 데이터 보존은 보장되지 않습니다.**
- 외부 PostgreSQL: `AGENT_STATE_DATABASE_URL`을 서버 비밀 설정에 등록하고 선택적으로 `psycopg[binary]`를 설치합니다. 실제 PostgreSQL 연결·마이그레이션 및 장기 보존 성능은 이번 검증에서 수행하지 않았습니다.
- 계획 복원 시 `RUNNING` 단계는 `INTERRUPTED`로 내려가며 자동으로 성공 처리되지 않습니다. 명시적인 재시도만 지원합니다.
- 계정 연결 해제 또는 위임 토큰 만료 시 계정별 저장물에는 접근할 수 없습니다. 인증 재연결 뒤 복원 가능합니다.

## 검증 범위

- v0.13 이전 회귀 테스트 모두 유지.
- LLM 구조화 계획 식별, 다중 턴 조건 수집, 정보 부족 시 중단, 정확한 금액 인용, 완료 단계 중복 호출 차단, 후보 수 부족, Live 변경 차단, 사용자별 SQLite 격리와 삭제, 인터럽트 복원 테스트 추가.
- 모든 OpenAI 출력은 모의 객체; 모든 ProjectAgain 요청은 모의 도구 또는 로컬 DEMO. 실제 원격 유료 모델/배포/모바일 UI는 미검증.

## 한계 및 후속 통합 검증

- 추천 이외의 13개 도구를 자유롭게 조합하는 범용 계획기까지는 구현되지 않았습니다. 현재 복합 계획의 지원 범위는 추천에서 시작하는 거래 준비 시나리오입니다.
- 다중 서버 공유, 예약 실행, 백그라운드 작업은 없습니다. Streamlit에서 사용자가 메시지나 버튼을 보낼 때 동기 처리합니다.
- 저장 후 클라우드 재배포에 견디려면 별도 PostgreSQL이 반드시 필요합니다.
- 공개 서비스에서 OpenAI 사용량 제한 및 비용 관리가 완료된 것은 아닙니다.
- 실제 ProjectAgain v0.13 서버와의 HTTPS 연동, 사용자 토큰 만료/재발급 후 복원, Streamlit 1.67 화면 검증, 외부 PostgreSQL 저장을 실환경에서 확인해야 합니다.
