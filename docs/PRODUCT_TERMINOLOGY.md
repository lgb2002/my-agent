# 제품 용어 및 표현 기준

서비스의 문구·프롬프트·도구 설명·개발 문서는 **사용자 업무와 실제 구현 상태**만 설명합니다.

| 권장 표현 | 의미 |
|---|---|
| 디지털 자산 거래 에이전트 / Asset Agent | 제품명 및 서비스 역할 |
| 매물 검색·추천 / 정적 실사 / 협상 초안 / 인수인계 | 핵심 사용자 업무 |
| 샌드박스 | 가상 매물·계정·거래를 사용하는 내부 테스트 실행 환경 |
| DEMO / `is_demo` / `AGENT_MODE=mock` | 기존 API·DB·설정과 호환되는 기술 식별자. 변경하지 않음 |
| 조회 전용 / 승인 대기 / 미검증 | 실제 권한·상태·불확실성을 나타내는 표현 |
| 품질 검증·회귀 테스트 | 제품 내부 품질관리와 테스트 활동 |

## 작성 원칙

1. 제품 화면과 에이전트 프롬프트는 사용자 업무, 실제 기능, 안전 제한과 결과만 설명합니다.
2. 샌드박스 데이터는 실제 거래처럼 표시하지 않습니다.
3. 모델이 자동 수행할 수 있는 업무와 사용자 승인 단계는 분리해 설명합니다.
4. 미구현 기능은 현재 지원하는 것처럼 묘사하지 않습니다.
5. API 필드명, 상태코드, 환경변수와 기존 저장 데이터는 문자열 정리 목적으로 변경하지 않습니다.
