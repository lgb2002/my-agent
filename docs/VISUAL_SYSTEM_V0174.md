# v0.17.4 시각 디자인 개선 · 구현 및 검증 기록

이 문서는 사용자 요청의 **타이포그래피, 정보 밀도, 화면 폭, 스크롤, 상태 표현, 도구 실행 피드백, 디자인 시스템 재정의**를 기존 v0.17.3 코드 위에서 구현한 결과를 기록한다. 본문에서 가리키는 예시 스크린샷은 임의 매물을 사용한 **정적 HTML/CSS 미리보기**이며 실제 Streamlit 화면은 아니다.

## 반영 사항

| 영역 | 이전 구현 | 변경 후 |
|---|---|---|
| 글자·행간 | 메시지 14px, 일부 결과 12px대 | 주요 본문 16px·행간 1.74, 보조 정보 약 14px, 캡션 약 13px |
| 메인 폭 | 1024px 고정 | 작업 중심 선택: 읽기 820px · 일반 1040px · 검색/추천/실사 1220px |
| 정보 밀도 | 캡션과 일반 문장 위계 약함 | 결과 섹션 제목·수량, 비교표, 확인해야 할 위험 행 분리 |
| 위험 근거 | 상태명과 근거를 짧은 캡션에 합침 | 항목명 + 상태 단어 + 근거 설명, 미확인·주의·문제·판매자 고지 구별 |
| 스크롤 | v0.17.3에서 단일 문서 스크롤 확보 | 그대로 유지. 대화 영역 최대 850px, 모바일 비교표만 자체 수평 스크롤 |

| 상호작용 | 기본 버튼/펼침 | 공통 최소 높이·포커스 강조·반응형 버튼 규칙으로 일치 |

## 파일

- `assets/style.css`: 디자인 토큰과 구성요소 단일 스타일 정의.
- `core/ui_design.py`: 화면 폭 분류, 위험 상태·근거 HTML의 안전한 표현.
- `app.py`: 상태별 레이아웃 마커, 실행 피드백, 근거 행과 모바일 비교 안내.
- `tests/test_visual_design_v0174.py`: 새 시각 의미·보안·계약 검증 15개.
- `DESIGN.md`: 제품 수준 디자인 시스템 규격.
- `docs/visual_static_preview_v0174.html`: 가상의 자료를 사용한 검증 HTML.
- `docs/visual_static_*px_v0174.png`, `docs/visual_qa_v0174.json`: 정적 Chromium 스크린샷과 측정 수치.

## 정적 브라우저 점검

```bash
python docs/build_visual_preview_v0174.py
python docs/check_visual_viewports_v0174.py
```

320·360·390·768·980·1280·1600px CSS 정적 뷰포트, 문서 가로 넘침, 버튼 터치 높이, 모바일 비교표 스크롤을 검사한다. 실제 본문·상태 정보의 색상 대비(배경 대비)는 계산 결과 약 5.86~13.75:1, 상태 태그의 배경 대비는 약 5.89~7.35:1이었다. 이는 일부 명시된 색 조합에 한하며 실제 앱 전체 UI 접근성 인증은 아니다.

## 아직 미검증

실제 Streamlit Cloud의 DOM과 위 CSS 선택자의 호환성, PC·모바일 터치/키보드·가상 키보드가 채팅 입력창을 가리는지, 다단계 실행 중 `st.status` 표시, 플랫폼 계정 연결·실 API 조회 및 OpenAI 유료 호출, 대화 복원과 네트워크 오류 상태. 배포 후 원본 데이터와 함께 시각 검수를 해야 한다.

## 배포 경계

실제 ProjectAgain 매물 API 전용이며 Mock 모드·가상 거래 DB를 추가하지 않는다. 계정별 인증·권한, AI 사용량 제한, 영구 저장, 거래 승인·실행 경로는 변경하지 않는다. 통합 로그인은 상대 플랫폼에서 인증 API 계약이 온 다음 개발한다.
