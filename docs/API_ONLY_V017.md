# v0.17 — 플랫폼 API 단일 데이터 출처

## 배경

실제 플랫폼 매물에는 **일반 매물과 플랫폼에 등록된 시연 매물**이 모두 있다. 둘 다 플랫폼의 `/api/v1/listings`에서 제공된다. `include_demo`는 서버 측 목록 필터이며 에이전트 내부 가상 플랫폼 사용 여부와 무관하다.

기존 내부 가상 거래 모드는 시험 목적으로 별도의 로컬 SQLite 및 JSON을 사용했고 Python import 시 초기화되는 과정에서 Streamlit Cloud 부팅 장애가 발생할 수 있었다.

## 적용 원칙

1. 플랫폼의 매물·협상·인계 정보는 HTTPS API에서만 획득한다.
2. 앱이 시작될 때 로컬 가상 매물 JSON·테스트 SQLite를 읽거나 초기화하지 않는다.
3. UI에는 외부 플랫폼 데이터와 관련된 검색 조건만 제공한다. 서비스 실행 모드 선택은 없다.
4. 사용자별 위임 토큰을 검증해야 개인 데이터를 조회할 수 있다.
5. API의 조회와 사람 확인 후의 제안 초안 제출 외에 에이전트가 실제 거래를 승인·실행하지 않는다.
6. 도구 목록에는 실제 플랫폼 계약으로 지원할 수 있는 기능만 표시한다.
7. 자동 테스트의 가짜 HTTP 응답과 임시 DB는 테스트 코드 안에서만 사용하며, 배포 사용자가 접근하는 가상 거래 모드가 아니다.

## 제외된 기능

- `services/demo_marketplace.py` 및 `fixtures/demo_contract.json`, 가상 거래 SQLite를 사용하는 런타임 경로
- 가상 사용자 역할 선택/가상 거래 확정 처리
- 실제 플랫폼과의 승인 계약이 없는 4개 가상 거래 변경 도구

## 남은 기능

- `MARKETPLACE_INCLUDE_DEMO` / 시연 매물 포함 토글: **계속 지원**
- 추천과 사용자별 조건 기억, 근거 중심 적합성 평가, 위험 평가
- 실제 API에서 조회한 매물의 정적 실사 및 판매자 본인 ZIP 정적 검사
- 외부 플랫폼의 사용자별 인증, 인수인계·제안 조회, 별도 확인 기반 제안 초안
- OpenAI 호출 비용·빈도 통제, 사용자 동의 기반 상태 저장

## 확인

`python -m scripts.run_tests`에서 API 계약의 모의 응답과 다른 기능의 회귀 검사를 실행한다. 유료 OpenAI 및 실서버 호출 성공을 보증하지 않는다.
