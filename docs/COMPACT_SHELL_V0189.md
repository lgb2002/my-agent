# Agent v0.18.9 — 컴팩트 첫 화면 / 대화 중심 사이드바 / 설정 모달

기준 소스: v0.18.8 전체 프로젝트. ProjectAgain 거래 플랫폼(Replit)의 코드와 배포 환경은 수정하지 않는다.

## 사용자 요청에 대한 변경

- **첫 화면:** 큰 테두리 소개 상자와 2×2 대형 설명 카드를 없앴다. 제목·한 줄 설명·실제 Streamlit `st.chat_input` 순서로 배치하고, 버튼 네 개는 한 줄의 작은 빠른 시작 항목으로 만들었다. 모바일에서는 2×2 배치와 최소 44px 터치 높이를 사용한다. 시작 버튼은 같은 기존 ChatAgent 요청 처리 경로를 통과한다.
- **사이드바:** 브랜드 → 새 대화 → 작은 매물 탐색/맞춤 추천 바로가기 → 최근 대화 검색·날짜별 목록 순으로 구성. 긴 대화 목록만 별도로 스크롤하고, 계정 상태와 **설정**을 하단에 배치한다. 개별 대화의 ⋯ 삭제 확인은 유지한다.
- **설정 모달:** Streamlit 기본 `st.dialog`를 이용하여 `대화(전체 삭제) / 매물(시연 필터) / 작업·기억(조건·계획 저장·복원·삭제) / ZIP 검사 / 계정(로그아웃·AI 사용량·도구 목록)` 다섯 탭으로 이동. 웹 페이지 전체를 바꾸거나 승인 흐름을 가로채지 않는다.
- **자동 저장:** ProjectAgain 계정으로 검증된 경우 Supabase PostgreSQL 대화 자동 저장을 기본으로 유지. 저장 선택 토글을 되살리지 않음. 조건·작업 계획의 *별도 동의*는 기존 정책에 따라 유지하며, 설정 모달이 닫혀도 선택 상태가 잃지 않도록 별도 세션 키에 기록한다.
- **ZIP 첨부 안전성:** 설정 모달에서 ZIP을 고른 것만으로 다음 일반 질문에 자동 첨부하지 않는다. 'ZIP 정적 검사 시작'을 누른 경우에만 현재 계정 범위·대화 ID에 연결된 파일을 메모리에 일시 보관해 정적 검사 요청에 사용한다. 4MB 제한, 사용 후 버퍼 삭제. DB/대화 보관에 ZIP 내용 저장 금지.
- **인증과 거래 정책:** 플랫폼의 API 데이터 원천, OIDC 로그인, Broker Refresh, 사용자 범위 격리, 승인 카드와 거래 실행의 분리, `ENABLE_LIVE_DRAFTS` 기본값 유지. 로그아웃은 기존 계정 인증 흐름을 거치고 서버 철회 성공 여부를 과장하지 않는다.

## 검증

- `python scripts/run_tests.py` — 회귀 테스트 280개 통과, 실패·오류 0개 (Python 3.13 오프라인 환경).
- `python docs/verify_compact_shell_static_v0189.py` — Chromium 정적 fixture에서 390/768/1280px 가로 넘침 없음. 데스크톱 빠른 버튼 높이 36px, 모바일 44px. `docs/compact_shell_static_*_v0189.png`는 **실제 Streamlit 렌더가 아닌 HTML/CSS 미리보기**다.
- **아직 확인 필요:** 실제 Streamlit Cloud에서 설정 `st.dialog` 열기·닫기, 다섯 탭의 동작, 계정 로그아웃, ZIP 검사 시작 후 모달 복귀, 모바일 사이드바 스크롤, 재로그인/대화 동기화. 외부 서비스에 실제 접속한 테스트로 주장하지 않는다.

## 배포 및 데이터 보존

- GitHub `my-agent`의 기존 파일을 v0.18.9 전체 ZIP 내용과 병합해 커밋·푸시하고 Streamlit Cloud 앱을 재시작한다.
- 기존 `.env`, `.venv`, 실제 Streamlit Secrets, Supabase 사용자 데이터, 개인 `data/` 등은 덮어쓰지 않는다. 새로운 Secrets, 스키마 초기화, 패키지 설치 스크립트, Replit 재배포는 필요 없다.
- `requirements.txt`는 기존 Streamlit >=1.50 조건을 그대로 사용한다. 이 버전에서 `st.dialog`가 제공된다.
