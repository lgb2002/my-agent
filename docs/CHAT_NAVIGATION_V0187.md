# ProjectAgain Agent v0.18.7 — 대화 중심 UI 및 계정별 Supabase 보관

## 사용자 화면

- 첫 진입: 기존 딥그린·오프화이트 디자인을 유지하면서 윤곽이 있는 소개 영역과 2×2 시작 카드 제공. 모바일에서는 1열.
- 사이드바: `새 대화` + 현재/최근 대화 목록 + 대화별 관리(`⋯` → 삭제 확인). 별도 `대화 보관함`, `대화 장기 보관`, `추천 조건 확인·수정`의 중복 메뉴 제거. 추천 조건은 원래 작업 영역의 인라인 수정 기능 유지.
- `시연 매물 포함`, 기존 작업/조건 저장, ZIP 검사, 도구 안내는 보조 메뉴에서 접근.
- **개발·DB 진단 버튼은 일반 UI에서 숨김.** 기존 진단 모듈과 테스트는 코드로 유지하여 장애 시 개발자가 사용할 수 있음.
- 일반 대화/보관된 대화는 메시지 기록을 처음부터 펼쳐 보여주되, 추천·실사·검색의 결과 우선 UI는 유지.

## Supabase 동작

- 기존 `AGENT_STATE_DATABASE_URL`이 연결된 PostgreSQL(Supabase Session Pooler 포함)을 사용. 별도 `SUPABASE_URL`이나 서비스 롤 키 불필요.
- 신규 테이블 `agent_chat_settings(owner_key,auto_save,updated_at)`을 `CREATE TABLE IF NOT EXISTS`로 생성. 기존 `agent_saved_conversations`의 구조/행은 변경하지 않음.
- **기본값 자동 저장 OFF**. 검증된 ProjectAgain 로그인으로 연결된 사용자가 `Supabase에 자동 저장`을 켜야 동작. 선택은 계정별 PostgreSQL에 기록되므로 같은 계정으로 재로그인해도 유지됨. 끄면 향후 저장만 중지하며 이전 저장 대화는 삭제하지 않음.
- 대화가 변경된 경우에만 자동 저장을 시도. 사용자의 이전 수동 보관 대화도 목록에 나타남. 다른 브라우저에서 선택하면 해당 대화의 저장된 문장/도구 요약을 불러옴.
- 저장 허용값: user/assistant의 문자와 안전한 도구명·상태·요약. **원본 API 응답, ZIP 파일, 접근 토큰, 승인 nonce/카드, 작업 실행 컨텍스트를 저장하지 않음.** 복원 후 근거/거래 상태는 플랫폼에서 새로 조회해야 함.
- 소유권: 수신한 ID를 신뢰하지 않고 플랫폼 `/auth/me`에서 실제 검증된 사용자로 `owner_key`를 구성. DB 모든 조회/수정/삭제는 `owner_key`와 `conversation_id`로 격리.
- 삭제 UI에서는 확인 절차 후 해당 대화의 계정 저장본까지 삭제. 클라우드 삭제 실패 시 브라우저 기록도 유지.
- 자동 저장 실패 시 브라우저 대화는 유지되며 비밀 문자열이 포함된 원본 오류나 DB 주소는 화면에 표시하지 않음. 비밀번호를 포함한 입력은 저장 거부될 수 있음.

## 호환성 및 운영 제한

- 기존 로그인/Broker 자동 토큰 갱신, 9개 도구, `ENABLE_LIVE_DRAFTS` 기본 비활성, 거래 승인 정책, AI 호출 제한 불변.
- 기존 수동 저장 대화는 삭제·초기화하지 않음. 별도 DB 마이그레이션 명령 불필요. **현재 Supabase 계정에 테이블 생성 권한은 필요**.
- 저장 대화 최대 표시 40개(서버 조회 최대 60개). 장기 다중 기기 동시 편집 충돌 제어 기능은 별도 작업이 필요.
- 과거 도구 스냅샷/추천 조건/진행 중인 워크플로 및 승인 상태는 대화 복원과 함께 자동 복구되지 않음. 기존 `저장한 조건 · 작업`에서 명시적으로 복원 가능한 것만 별도 취급.
- 기존 로컬 브라우저 세션의 미저장 대화는 배포 시 소실될 수 있으므로 중요한 대화는 새 버전에서 계정 연결 후 저장 동의를 확인해야 함.

## 배포·실환경 점검

1. v0.18.7 전체 ZIP의 앱·CSS·core·tests·docs 코드를 기존 GitHub 저장소에 병합. `.env`, `.venv`, 실제 `data/`, GitHub/Streamlit Secrets, 서버 PostgreSQL 내용을 덮어쓰지 않음.
2. Streamlit Cloud 재부팅. Replit 플랫폼 재배포나 Secret 신규 발급 불필요.
3. 로그인 상태 확인 → 사이드바 `Supabase에 자동 저장` 켜기 → 대화 입력 → 최근 목록 생성 확인.
4. 새 대화 → 원래 대화 열기 → 새로고침/다른 기기 로그인 후 저장 대화 열기. 같은 계정 자료만 보여야 함.
5. 대화 삭제 확인 → 원래 대화만 사라지는지 확인. 저장 OFF → 새 대화가 클라우드에 저장되지 않는지 확인.
6. 매물 검색·추천·실사·ZIP 검사·계정 API 조회·거래 승인 대기 화면의 기존 기능을 확인.
7. 390px/768px/1280px 정적 브라우저 화면은 `python docs/verify_navigation_preview_v0187.py`로 별도 검사 가능(Playwright/Chromium 선택적, Streamlit 실제 실행이 아님).

**검증 범위:** 오프라인 unittest + Chromium의 정적 CSS/구조 fixture. 실제 Streamlit Cloud UI, Supabase PostgreSQL, Replit API, 모바일 키보드/터치 E2E는 배포 후 직접 확인해야 함.
