# v0.6 인터페이스 변경 기록

**우선순위:** 대화 → 매물 결과 → 근거/도구 기록 → 승인 요청. 사용자가 여러 기능 탭을 외울 필요가 없도록 구성했습니다.

- 상단의 긴 제품 소개를 제거하고 작은 작업 공간 제목과 연결 상태만 표시
- 첫 대화 전에는 4개 시작 동작과 짧은 안내만 노출
- 실제 대화가 시작되면 시작 카드 대신 메시지와 도구 실행 내용이 중심이 되도록 설계
- 도구의 원시 JSON은 접힌 **결과 상세**에서만 제공
- 사이드바에는 역할/인증, 새 대화, 필요 시 열어보는 도구·작업 기록, 판매자 ZIP 첨부를 배치
- 플랫폼 토큰은 비밀번호형 입력을 통해 사용자별 세션에서만 사용하며 계정 변경 시 기존 대화와 분리
- 데스크톱/모바일에서 가독성을 유지하도록 너비, 간격, 버튼, 글자 크기 조정
- DEMO 승인 카드는 채팅 아래 별도 확인 단계로 유지. UI 수정으로 승인 경계를 완화하지 않음

정적 CSS와 Streamlit API 구성을 코드 차원에서 검토했으며, 브라우저별 시각 검수는 별도로 필요합니다.
