# ProjectAgain Agent v0.19.1 — 성능, 실행 상태, 컴팩트 사이드바

## 적용 영역

- **대화 선택**: 위젯 `on_click`에 선택 대화 ID만 기록한 뒤, 인증된 이번 실행에서만 해당 소유자의 Supabase 보관본을 읽고 곧바로 메인 화면에 렌더링. 선택·새 대화·더보기 메뉴에서 불필요한 추가 `st.rerun()` 제거. 인증은 캐싱하지 않음.
- **대화 목록**: 검증된 계정의 제목/날짜 메타데이터만 18초 동안 세션별 캐시. 다른 계정으로 전환하면 기존 캐시는 소유자 키가 달라 사용되지 않음. 저장·삭제 시 캐시 무효화. 가격/거래/토큰/권한은 캐시하지 않음.
- **대화 저장**: 매 렌더마다 전체 도구 결과를 직렬화하고 SHA 계산하는 대신, 메시지 추가마다 증가하는 revision으로 변경 여부를 O(1) 판단. 모든 답변은 완료 직후 Supabase에 저장 시도. 과거 v1/v2 대화 호환 및 자동 삭제 없음.
- **DB 연결**: `psycopg_pool`의 프로세스 내 최대 3개(환경설정으로 1~6 제한) 연결을 재사용해 워크플로·대화·AI 사용량 장부의 반복적인 연결 비용을 감소. `psycopg_pool>=3.2,<4`를 **루트 requirements.txt에 직접 추가**함. DB URL, 비밀번호 출력 없음. 각 SQL 호출의 계정 소유자 검증·동시성 잠금 및 거래 승인 정책 유지.
- **긴 대화**: 한 번에 최근 24개 메시지만 렌더링하고, 과거 24개씩 더 표시. 원본 저장 기록을 자르거나 버리지 않음. 대화 복원 후 과거 매물 스냅샷은 여전히 조회 당시 정보만 표시함.
- **AI 도구 진행**: `ChatAgent`와 워크플로 도구 호출이 시작/종료된 뒤에만 실제 단계별 한국어 상태를 기록. 성공·실패를 구분하며 사전에 예상한 단계/건수를 완료된 것처럼 표시하지 않음. 비밀값·도구 입력 파라미터를 진행 상태에 출력하지 않음.
- **AI 요청 최적화**: 한 단계짜리 단순 추천에서는 별도 복합 작업 계획 모델 호출을 건너뛰며, 상세 AI 해설 요청이 없는 일반 추천은 선택적 모델 해설 호출을 생략. 기본 추천 후보·점수·근거·실사 경계는 그대로 유지. 다중 도구 호출/검증/승인 판단은 기존 모델+서버 실행 경로 사용.
- **화면 깜빡임 완화**: 일반 답변 이후 전체 `st.rerun()` 대신 현재 대화에 사용자 메시지와 AI 결과를 즉시 추가 출력. 신규 승인 카드·기타 안전 확인이 필요할 때만 기존 재실행 경로 유지. Streamlit 자체 위젯 실행에 따른 기본 재렌더링까지 제거되지는 않음.
- **시간 측정**: `설정 → 계정 → 최근 요청 처리 시간`에서 최근 모델·도구·인증·대화목록·대화 불러오기·렌더링 시간 확인. 측정치는 개인 메시지/토큰/DB URL 없이 브라우저 세션에만 보관. Streamlit Cloud의 실제 네트워크·브라우저 성능은 배포 후 확인.
- **사이드바**: 데스크톱 새 대화 35px, 계정 트리거 36px, 계정 팝오버 항목 34px. 모바일은 터치 접근성을 위해 44px. 기존 상단 브랜드, 대화 목록/검색, 하단 계정 메뉴만 유지하며 대화 콘텐츠·승인 카드의 버튼 크기는 변경하지 않음.

## 알려진 한계 및 실배포 검증

- **실제 OpenAI 토큰 스트리밍은 아직 적용하지 않음.** 도구별 작업 진행 상태와 답변 생성 완료 후 즉시 표시만 지원. 토큰 스트리밍은 유료 호출의 예약·정산·중도 취소 안전성을 검증한 뒤 별도 작업으로 구현해야 함. 완료 결과를 타이핑하듯 보여주는 가짜 스트리밍은 추가하지 않음.
- Streamlit의 일반 위젯은 여전히 전체 스크립트 재실행을 유발할 수 있다. 인증/권한을 생략하는 UI 캐싱은 하지 않는다.
- 실제 Streamlit Cloud에서 시간 측정, 모델 응답, PostgreSQL ConnectionPool 연결 제한과 다중 사용자 접속, 다른 기기 복원, 화면 깜빡임, 모바일 팝오버 버튼 크기를 확인해야 한다. 로컬 순수 Python 오프라인 테스트만 완료됨.
- 배포: 기존 v0.19.0 ZIP의 모든 파일 유지, `requirements.txt`에 추가된 `psycopg_pool` 패키지가 **자동 설치**되도록 GitHub에 반영. Streamlit Cloud 재부팅. Replit 플랫폼·Supabase DB 스키마/Secrets 변경 없음.
