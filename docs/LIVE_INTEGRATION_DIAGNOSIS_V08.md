# 연결 문제의 코드상 원인 및 진단 기준

1. **매물 0건의 가장 유력한 이유:** `MARKETPLACE_INCLUDE_DEMO=false` 기본값과 Live 사이드바 체크박스 꺼짐으로 공개 API 호출에 `include_demo=false`가 명시됨. 플랫폼이 시연 매물만 보유하면 정상 HTTP 200이어도 빈 목록을 받음. 이는 가능성이 높은 원인이며, 운영 요청을 직접 캡처한 확인 결과는 아님.
2. **OpenAI 비활성 표시:** `core.config`는 `OPENAI_API_KEY`와 별개로 `ENABLE_OPENAI_CHAT`이 명시적으로 true여야 한다. 기본은 false. Cloud Secrets 로딩을 앱 시작 시 명시적으로 보강했고, 화면에 어떤 조건이 실패했는지 보여줌.
3. **Secrets의 12시간 토큰:** `MARKETPLACE_API_KEY`는 이전 v0.6부터 공용 사용을 금지하여 일부러 무시함. 공개 매물 조회는 익명. 개인 인증 확인은 사용자별 토큰 입력 후 `/api/v1/auth/me` 200으로 별도 검사.
4. **실제 동작 검증:** 사이드바 진단 버튼은 `GET /api/v1/listings`를 두 필터로 각각 호출하며, 사용자별 토큰이 있는 경우에만 `/api/v1/auth/me`를 호출. 상태 코드, 현재 필터, `items` 길이, `total_estimate`와 페이지 존재만 취급. 토큰/키/개인 정보는 UI에 출력하지 않음.
5. **환경 한계:** 이 작업 세션에서는 사용자의 Streamlit Secrets와 Replit 실제 운영 호스트를 읽을 수 없었으므로 실제 운영 응답은 미검증. 모의 HTTP 56개 회귀 테스트와 별도 분리해 기록함.

## 안전한 결과 해석

- 공개 HTTP 200 + 일반 0건 + 시연 포함 양수: 시연 필터 때문에 0건으로 보였을 가능성 매우 높음.
- 공개 HTTP 200 + 양쪽 0건: 해당 API 기준 반환 매물 없음. ACTIVE 상태·서버 주소·다른 검색 조건을 확인.
- 공개 401/403: 공개 API 또는 배포 인증 설정 문제. 해당 요청이 익명으로 전송되는지 확인.
- JSON/계약 오류: 응답 최상위 `items`가 배열인지 확인.
- 개인 인증 401/403: 위임 토큰 만료·철회·권한 검토. 공개 API 결과와 별개.
- OpenAI '활성': 키와 플래그가 설정된 상태를 뜻할 뿐, 과금 API 호출 성공을 의미하지 않음.
