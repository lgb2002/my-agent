# ProjectAgain Agent v0.19.0 — 대화 메인 화면 · 조회 스냅샷 · 사이드바 정리

## 사용자 경험

- 기존에 Supabase에 보관한 대화를 선택하면 별도의 ‘대화 기록’ 접이식 박스 없이 메인에 사용자/에이전트 메시지를 시간순으로 표시합니다. 선택한 대화의 마지막에서 그대로 이어서 입력합니다.
- 새 버전 이후의 검색·추천·공개 자료 검토·계정별 읽기 도구의 **화면 표시에 필요한 구조화된 결과**를 메시지와 함께 보관합니다. 결과에는 가능하면 조회 당시의 시간(KST)을 표시합니다. 예전 v1 저장 기록은 기존에 저장한 문장과 도구 요약만 표시합니다. 저장되지 않았던 과거 API 응답을 소급 생성할 수는 없습니다.
- 저장한 결과는 당시 기록이지 실시간 거래 상태가 아닙니다. 사용자가 누르는 ‘최신 정보 다시 조회’는 일반 에이전트 질문으로 들어가고 실제 플랫폼 API가 현재 데이터를 재조회합니다. 보관된 가격·판매 상태·추천 점수는 현재값이라고 표시하지 않습니다.
- 사용자가 이미 선택했던 매물 UUID 순서만 읽기 전용 참고 문맥으로 복원할 수 있습니다. 다음 페이지 커서, 이전 거래 승인·신청 토큰·미완료 거래 실행 단계·ZIP 바이트는 절대 복원하지 않습니다. 그 UUID로 실사 요청 시 플랫폼 API를 다시 조회합니다.
- 사이드바의 중복 바로가기 제거, 새 대화와 최근 대화 목록·검색·날짜 구분, 하단 계정 팝오버(계정 전환/설정/플랫폼 사이트) 구조로 조정했습니다. 비로그인자는 플랫폼 웹사이트로 이동해 회원가입을 진행할 수 있습니다. 플랫폼의 회원가입 전용 경로는 추정하지 않습니다.
- ZIP 검사는 사용자가 관련 대화를 진행할 때만 메인 영역에 압축된 입력을 제공하며, 기존 설정 모달의 검사는 호환성을 위해 남겨 둡니다. 두 경로 모두 해당 대화 ID에 묶인 4MB 정적 검사만 허용합니다.

## 데이터 저장 보안 및 호환성

- 기존 PostgreSQL 테이블 `agent_saved_conversations`의 `transcript_json`에 v2 형식으로 저장합니다. **별도 DB 마이그레이션/새 Secrets/라이브러리는 필요하지 않습니다.** v1 JSON도 그대로 읽을 수 있습니다.
- `core/chat_history_snapshot.py`는 도구별 허용 필드 목록만 저장합니다. 원본 HTTP 응답 전체, 쿠키, 접근/갱신 토큰, Broker 세션·증명, 서명, 비밀키, 판매자의 비공개 파일, 거래 실행용 인자/승인 카드, 내부 컨텍스트를 저장하지 않습니다. 도구 응답에 제3자가 포함한 비밀정보 형태도 알려진 패턴에 대해 제외합니다.
- 조회 이력은 계정 UUID를 플랫폼에서 검증하고 파생한 해시 소유자 범위로만 접근합니다. 다른 계정은 대화 목록·상세 조회 및 삭제 불가. 비로그인 대화는 서버에 영구 저장되지 않습니다.
- 기존 전체 삭제 기능은 본인 대화만 지우고 구매 조건·작업 체크포인트는 삭제하지 않습니다.
- 최대 저장 크기는 대화당 8MB입니다. 초과하면 **앞부분을 자르지 않고** 저장을 거절하고 오류를 안내합니다. 이 제한은 서비스 수명에 따른 성능·저장 비용 운영 정책으로 재검토할 수 있습니다.

## 승인·API 제한

- OAuth Broker 자동 갱신, 최소 권한, 별도 사용자 승인, 실거래/결제/권리 이전 플랫폼 전용 정책은 이전과 동일합니다.
- 저장된 결과에서 직접 제출·승인을 재실행하지 않습니다. `prepare_offer` 같은 상태 변경 도구의 승인 정보는 저장하지 않습니다.
- 과거 저장 내용의 외부 조회 결과를 최신 데이터로 취급하는 UI 문구·자동 재시도는 배제합니다.

## 검증 범위

- Python 오프라인 회귀 286개 통과, 실패 0/오류 0. 신규 테스트는 스냅샷 허용목록, 계정 격리, v1 호환, 당시 시각, 8MB 제한, 안전한 재조회, 메인 대화 렌더 구조를 검사합니다.
- 실제 Streamlit Cloud 브라우저, Supabase 동시 저장, 계정 전환/다른 브라우저 복원, 좁은 화면에서의 사이드바 스크롤은 배포 후 확인이 필요합니다. 정적 CSS 검증은 실제 호스팅 E2E를 대체하지 않습니다.
