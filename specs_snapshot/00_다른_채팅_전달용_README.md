# 국비 AI 에이전트 ↔ 초소형 디지털 자산 거래 플랫폼 — 프로젝트 인수인계 문서

- 작성일: 2026-11-12
- 상태: **설계 기준선 v1.0 / 미구현·미검증 내용은 명시적으로 구분**
- 소유·기획·개발: 사용자 1인. 팀원 없음. 교육기관 외부 플랫폼 사용 및 코드 소유권 문제 없음(사용자가 확인한 프로젝트 전제).
- 임시 내부 프로젝트 코드명: `micro-asset-market`(플랫폼), `micro-asset-agent`(국비 에이전트). 공식 서비스명은 **미확정**.

## [절대 우선] 비용·작업 원칙

**Replit Agent나 ChatGPT–Replit 연동 도구를 사용해 앱 생성·수정·배포를 지시하지 않는다.** 이전에 Replit Agent가 Free Mode 대신 Max Mode처럼 실행되어 사용자가 예상하지 못한 비용을 부담했다고 보고했다. 재발 방지를 위해 이 프로젝트에서 **에이전트 실행 호출 자체를 금지**한다. 의도적으로 유료 Agent를 쓰자는 새로운 명시적 결정 전에는 재사용하지 않는다.

- 코드 작성·수정·테스트·ZIP 제작: **ChatGPT 작업 환경**에서 수행한다.
- 결과물: 전체 소스 ZIP 또는 변경 파일 ZIP + 변경내역 + 검사 결과. 매 단계 파일 생성 후 링크 전달.
- Replit은 사용자가 **수동으로 소스 업로드·실행·배포할 환경**으로만 고려. Replit에서 AI 빌더/Agent 자동 실행을 호출하거나 권유하지 않음.
- API 사용료, 서버 배포비, 외부 모델 비용, LLM 토큰 비용도 별도 예산 통제. 기본은 DEMO/DRY_RUN/모의 결제.
- 부득이하게 Replit과의 직접 통합이 필요한 경우에도 먼저 사용자에게 비과금 수동 대안을 제공한다.

## 1. 전체 제품 비전

한국의 개인 개발자·1인 디지털 창업자가 소형 앱, 웹서비스, 코드, 프로그램, AI 에이전트, 미출시/실패/중단 프로젝트 등을 매도·매수하는 마켓플레이스를 구축한다. 중심 가격은 **5만~100만 원**(상한은 아님). 성공한 사업의 EXIT뿐 아니라 실패·중단 프로젝트의 잔존 자산을 재활용하는 **프로젝트 순환 시장**이 목표.

AI는 매물 추천, 실제 동작·운영권 이전 가능성 실사, 결함에 따른 보완·가격·조건 협상, 새 환경에서의 인수인계 검증을 수행한다. **AI가 법률상 소유권·계약을 스스로 확정하거나 돈을 보관·송금하지 않는다.**

## 2. 두 프로젝트는 독립적으로 개발

| 구분 | A. 독립 웹 플랫폼 | B. 국비 AI 에이전트 |
|---|---|---|
| 목적 | 판매자·구매자·매물·제안·거래 상태를 저장·운영 | 매물 분석·추천·협상 초안·인수인계 작업 실행 |
| UI | React + TypeScript 기반 반응형 웹 | 기존 국비 프로젝트의 Streamlit |
| 서버 | Python FastAPI 권장, PostgreSQL, 객체 저장소 | Python 서비스/모듈, 작업 큐 및 상태 DB(필요시), 도구 어댑터 |
| 관계 | 외부 API를 제공하는 **원본 데이터·권한 시스템** | API 호출을 수행하는 **외부 위임 클라이언트** |
| 현재 | ChatGPT에서 직접 개발 후 Replit에 수동 반입 | 기존 Streamlit 채팅에서 계속 개발 |
| 상용화 | 초기 플랫폼 단독 운영 가능 | 국비 종료 후 같은 에이전트 엔진을 플랫폼에 통합 |

## 4. 기존 Streamlit 채팅에 그대로 전달할 문구

> 기존 Streamlit AI 프로젝트를 '초소형 디지털 자산 거래 플랫폼과 API로 연동되는 국비 AI 매수·매각 대리 에이전트'로 구체화한다. 첨부한 01번 전체 설계 명세서를 기준으로 기존 코드/requirements/Streamlit 버전을 먼저 분석한 후, 기존 기능을 임의 삭제하지 말고 안전한 단계별 변경 계획을 만들어 ChatGPT 안에서 직접 구현해 달라. 외부 거래 플랫폼 API는 03번 OpenAPI 계약을 따르며, 플랫폼이 준비되지 않았을 때는 동일 계약의 Mock API를 사용한다. Streamlit은 업무 콘솔일 뿐 실제 에이전트 작업·상태·검증은 독립 백엔드에서 처리한다. **Replit Agent / Replit 자동 개발 도구를 호출하지 말고, 완성 파일/ZIP만 이 채팅에 제공**한다. 05번 평가 매트릭스의 수용 테스트로 결과를 검증한다.

## 5. 플랫폼 개발 채팅에 그대로 전달할 문구

> 첨부한 02번 플랫폼 설계 명세서, 03번 OpenAPI 계약, 04번 SQL 초안, 05번 수용테스트를 기준으로 React+TypeScript/FastAPI/PostgreSQL 기반 웹 플랫폼의 동작하는 MVP를 ChatGPT 안에서 직접 개발한다. 기능을 데모처럼 꾸미지 말고 실제 인증·RBAC·매물 CRUD·검색·제안·역제안·감사로그가 서버에 저장되어야 한다. 프로젝트 소스 파일은 공개 매물에 노출하지 않으며, 저작권·이전 가능성은 확인 전 '미검증'으로 표시한다. 실제 결제, 계약 자동체결, 임의 코드 실행은 초기 범위에서 제외한다. **Replit Agent나 Replit 자동 개발 연결을 절대 사용하지 않는다.** 전체 소스 ZIP과 테스트 결과를 전달하고 Replit에는 사용자가 수동 배포한다.

## 6. 상호 운용의 비협상 규칙

1. **플랫폼이 거래 상태 및 권한의 유일한 원본(Source of Truth)**. 에이전트는 플랫폼 DB에 직접 접근 금지.
2. 계약은 `/api/v1` 버전 고정. 변경은 별도 버전/호환성 정책 적용.
3. 에이전트가 만드는 협상안·수정안은 **초안**. 외부 제안·수락·권리 이전·송금은 사용자 승인이 전제.
4. 시연용 데이터는 `is_demo=true`, DEMO 환경은 실제 회원/결제/거래와 분리.
5. 어떤 분석도 증빙 없으면 `unverified` 또는 `not_tested`. AI 추정 사실을 검증 완료로 표시 금지.
6. 타인의 코드는 기본적으로 비신뢰 입력. 격리 실행 환경이 없으면 동적 실행은 수행하지 않고 정적 검사만 실시.
7. 파일 저장·평가·상태와 비용은 감사 추적 가능해야 함.

## 7. 실행 우선순위

- **P0 공통:** 데이터 계약, 로그인, 접근제어, Listing/Offer API, DEMO fixture, 표준 오류 포맷.
- **P0 에이전트:** Mock API 연동, 추천 1개 E2E, 정적 실사, 승인 기반 협상 초안, 결과 보고서.
- **P1:** 제한된 격리 실행 실사, 다단계 역제안, 증빙 파일·인수인계 테스트, 독립 평가.
- **P2 상용:** 지급/에스크로, 권리 양도 계약 프로세스, 분쟁, 실사용자 거래, 보안 감사, 운영 모니터링.

## 8. 사실과 가정 구분

- 한국에서 소형 디지털 자산 거래 수요가 증가할 것이라는 것은 **유망한 사업 가설**, 확인된 예측이 아님.
- 5만~100만 원은 목표 가격대이지 실거래 통계가 아님.
- AI 감정 가격과 권리 여부는 자동 확정할 수 없음. 테스트 결과 + 불확실성 + 거래 당사자 승인이 핵심.
- 문서 속 예시 매물, 매출, 테스트 목표와 성과 수치는 **설계 예시**, 실제 거래 실적이 아님.
